# M18-05 本地 Web App 集成与浏览器验收

- 状态：设计冻结，等待 M18-04
- 前置：M18-04
- 必读：`spec/system/web-app.md` 全文、`plan/design-m18-ui.md` 全文、`plan/README.md` 第 4–6 节

## 交付

- 本地静态 Web App 启动路径和交互基准
- 浏览器回归看板、导航、MAO、两层画布、Foreman、Harness 选择、资源请求、资产和日志
- 节点拖动、平移、缩放、切层和刷新恢复验证
- 浏览器控制台错误清理
- 根目录和验证目录临时截图、Playwright 输出和缓存清理
- demo 与正式控制面边界记录

## 验收

- 默认看板无需登录
- 工厂层只有厂区，厂区层只有 Operator 和 Machine
- Foreman 只在编排画布出现，且能够自动应用 mock 结果
- Foreman 与 Operator 的 Harness 选择可用
- 节点拖动稳定，布局可恢复
- 普通流程无审批按钮，资源请求和异常有上下文
- 根目录没有临时截图或 Playwright 输出
- `node --check tmp/m18-ui-demo/app.js` 通过
- 浏览器回归无未处理控制台错误

## 不做

- 不新增后端 Factory、Workarea、用户或租户实体
- 不新增控制面 LLM 调用
- 不以截图代替交互验证
- 不提交或推送，除非用户另行明确要求
