## 错误示范与正确示范

**在事务里跑沙箱**

```python
# ✖ with db.tx(): sandbox.exec(...)
# ✔ result = sandbox.exec(...)  # 事务外；结果出来再开短事务落库
```

**预算超了还重试**

```python
# ✖ if code == 'BUDGET_EXCEEDED' and failed < retries: retry()
# ✔ BUDGET_EXCEEDED 直接 DEAD，不收货、不检验、不封存
```

**检验之前把候选写进 outputs**

```python
# ✖ job.outputs = report.outputs; gate.inspect(...)
# ✔ 只有 verdict == 'pass' 的那个事务里才写 outputs
```
