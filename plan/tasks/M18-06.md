# M18-06 真实 Web API 与本地启动

- 状态：未开始
- 前置：M18-05
- 必读：`spec/system/web-app.md` 全文、`plan/design-m18-ui.md` 第 11–12 节、`plan/README.md` 第 6 节

## 交付

- 新增 `factory web` 本地启动命令
- Web App 绑定 `127.0.0.1`，不提供登录、账号、租户或多用户流程
- 提供 `/`、`/healthz` 和 `/api/web/*` 同源入口
- 实现 bootstrap、图、资产、日志、talk、harness、constitution 只读 API
- API 错误使用稳定 JSON 结构，并向前端传递真实服务不可用状态
- API 响应不包含密钥值、凭据、Authorization、Cookie、完整 transcript 或内部敏感路径

## 验收

- `tests/system/test_m18_web_api.py` 全部通过
- `factory web --root <root> --provider local --port 0` 能绑定并返回实际端口
- `/`、`/healthz`、`/api/web/bootstrap` 返回合法响应
- 未启动 serve 时 talk 写入返回真实异常，不伪造成功
- 旧 `factory console` 命令和登录契约未被修改
