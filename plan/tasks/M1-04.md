## 必读（读完再写代码）

- sandbox.md 5.3（镜像解析：仓库 digest → 本地镜像 ID 回退）
- sandbox.md 5.6（LocalProvider 的命令映射与路径映射、环境不继承宿主）


6. 有 Docker 的机器上先 `uv run python tools/build_test_images.py`，再用 `MAO_REQUIRE_DOCKER=1` 跑验收。

```python
# ✖ argv += ["--network", "host"]
# ✔ argv += ["--network", "bridge" if allow_unproxied_egress else "none"]
```

**Local 继承宿主环境，测试在你的机器上碰巧通过**

```python
# ✖ env = {**os.environ, **spec.env}
# ✔ env = mapped_spec_env | windows_essentials | {"PYTHONIOENCODING": "utf-8"}
```

**超时让异常冒泡**

```python
# ✖ subprocess.run(argv, timeout=t)  # TimeoutExpired 抛给 Runner
# ✔ except subprocess.TimeoutExpired: kill(); return ExecResult(None, True, elapsed)
```

## 规范没写到时

- 规范没写的 docker 参数一律不加。
- Windows 路径原样写进 `--mount` 的 `source`，不 `resolve()`、不换斜杠。
- `close` 重复调用是空操作。

## 不要做

- 不要修改受保护文件（`plan/protected.lock` 登记的规范、验收测试、夹具、harness）。hook 会拒绝；绕过也会被 `lock --verify` 发现。
- 不要新增依赖，不要调用任何 LLM API，不要 `shell=True`，不要在 `base.py` 以外读时钟或生成随机数。
- 不要实现后续任务的功能；碰到“下一步才需要”的东西，按规范的“不做什么”表拒绝。
