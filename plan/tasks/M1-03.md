## 要做什么

按 `warehouse.md` 实现 `mao.warehouse`：

- CAS 布局 `$FACTORY_ROOT/cas/sha256/<2 hex>/<其余 62 hex>`。路径只用 `pathlib`。临时文件放在 `root/tmp`，不要用系统临时目录。
- Bean id 是 `{"type","meta","payload"}` 规范 JSON 的 SHA-256。`media_type_of` 按第 5.3 节的后缀表，不要用 `mimetypes`。
- `add` 登记未封存候选，幂等。`seal_many` 在一个事务里封存整批；中途失败整批回滚。facts 与首次封存不一致是 `FACTS_CONFLICT`。
- `record_lineage` / `lineage` / `materialize` / `list` / `verify` 按第 5 章。`bean.json` 的字段与 README 4.3 相同，本模块自己组装，不要 import `mao.values`。
- 错误码用字符串字面量，登记进 `CODES`。

签名以 README 4.4 为准，不要改。`Context.open` 不在本任务的 `paths` 里；它由 M1-01 按 foundation 5.11 装配 `Warehouse(root, db, clock)`。验收里的 `test_context_open_layout` 检查装配结果。对不上就记录并停下，不要去改 `context.py`。
