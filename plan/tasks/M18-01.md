# M18-01 本地 Web App 壳与四入口

- 状态：设计冻结，等待 M17 阶段门通过后实现
- 前置：M17 阶段门通过
- 必读：`spec/system/web-app.md`、`plan/design-m18-ui.md` 第 1–3、6、8–10 节、`plan/README.md` 第 6 节

## 交付

- 独立本地 Web App 用户入口，默认进入看板
- 侧边栏固定为看板、编排、资产、日志
- 侧边栏默认完全离屏
- 可拖动 MAO 悬浮按钮，支持左右停靠和垂直位置恢复
- 无登录、账号、租户、多用户和用户菜单
- 清理传统顶部导航和额外底部模块
- 本地布局偏好恢复，浏览器存储不承载业务事实

## 验收

- 浏览器打开后无需登录即可看到看板
- 侧边栏只有四个入口且顺序正确
- MAO 拖动不触发导航，释放后侧边栏从对应侧滑入
- 刷新后恢复 MAO 停靠侧和垂直位置
- 页面不存在用户、租户、邀请和多用户配置入口
