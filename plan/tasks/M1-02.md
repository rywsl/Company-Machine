## 要做什么

按 `snapshot.md` 实现 `mao.snapshot.Snapshot` 与 `mao.values`：

- `Snapshot.load` 调用 `mrl.factory.check.check_registry`。有 error 就 `FactoryError("REGISTRY_INVALID", ...)`。epoch 是 `e-` 加目录树哈希的前 16 位十六进制（第 5.2 节）。
- `key` / `doc` / `spec` / `type_key` / `is_subtype` / `facts_decl` / `validators` / `properties` / `always` / `compiled` 按第 5 章的算法，从检查结果的关系里取数，不要在 Python 里重写子类型。
- `compiled` 覆盖 factory-profile 第 4 章的每一个表达式位置，加载时用 `mrl.factory.sites.site_env` 编译，运行期只从缓存取。
- `bean_value`、`inputs_value`、`params_value`、`property_env`、`accept_env`、`approval_env`、`recipe_env`、`runtime_env` 的签名与 README 4.3 逐字相同，值的形状与 `mrl.factory.sites` 的类型环境一致。

签名以 README 4.2、4.3 为准，不要改。错误码用字符串字面量，并登记进 `mao/errors.py` 的 `CODES`。
