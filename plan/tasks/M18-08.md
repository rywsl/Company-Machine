# M18-08 Foreman 对话真实写入与刷新

- 状态：未开始
- 前置：M18-07
- 必读：`spec/system/web-app.md` 第 6–8 节、`plan/design-m18-ui.md` 第 6、11–12 节

## 交付

- `POST /api/web/talk` 通过现有 `talk.post_human` 写入 Foreman mailbox
- GET talk 返回安全的对话摘要和状态
- 前端发送后展示 queued，并通过刷新观察 running、answered、failed 或 exception
- serve 不可用、Foreman 未配置或输入无效时展示真实异常上下文
- 普通流程不出现应用候选方案、批准运行或人工确认按钮

## 验收

- `tests/system/test_m18_web_talk.py` 全部通过
- 成功写入的响应状态为 queued 或可观察的现有状态，不宣称已完成
- talk 数据不包含秘密值或完整内部 transcript
- serve 关闭时 POST 返回稳定错误码
