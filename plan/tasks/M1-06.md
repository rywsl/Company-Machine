## 要做什么

按 `gate.md` 实现 `mao.gate`：

- `check_inputs`：不存在、未封存、类型不符、`requires` 不成立、端口缺失或基数不对，一律 `FactoryError("INTAKE_REJECTED", ...)`，原因放在 `detail["problems"]`。不要抛 `BEAN_NOT_SEALED`。
- `inspect`：五个 stage 字符串只能是 `structure`、`validator`、`property`、`accept`、`consistency`。meta_schema 用 stage `consistency`、name `meta_schema`。
- validator 按第 4.4 节在沙箱里跑。`run` 原样传给 `exec`，不要自己把 `/bean/...` 翻译成宿主路径。退出码 1 是 reject；超时、坏 JSON、facts 形状不对是 `verdict="error"`，detail 以 `设施故障：` 开头。
- `inspect` 和 `admit_external` 只 `add` 候选，不调用 `seal_many`。通过之后 `warehouse.get(id).sealed` 仍是 `False`。
- 属性与 accept 只用 `snapshot.compiled` 和 `property_env` / `accept_env`。求值抛 `EvalError` 就是不通过，不要当成 `True`。

签名以 README 4.7 为准，不要改。错误码用字符串字面量，并登记进 `CODES`。
