## 目标

实现 `mao.gate`：来料检验 `check_inputs`、出厂检验 `inspect`、外部物料准入 `admit_external`。检验顺序与 verdict（pass / reject / error）的区分是本任务的核心。

## 必读（读完再写代码）

- gate.md 第 5 章（结构 → validator → 属性 → accept 的顺序）
- gate.md 5.4（validator 协议：退出码 0/1/其他）
- gate.md 第 8 章（错误示范）

## 步骤

```bash
uv run python tools/harness.py task start M1-06
uv run python tools/harness.py pytest tests/acceptance/m1/test_m1_06_gate.py
```

1. 按 gate.md 第 3 章写 `Check`、`GateReport`（`to_json`、`digest`）。
2. 实现 `check_inputs`：存在、已封存、类型兼容（名义子类型）、`requires`。失败统一 `INTAKE_REJECTED`，`detail.problems` 列全部问题。
3. 实现 `inspect`：收集候选 → 结构检查 → 在沙箱里跑 validator（argv 原样传给 Provider，不做路径翻译）→ 属性与 accept（MRL 编译好的表达式）→ 汇总 feedback。
4. validator 退出码不是 0/1、输出不是 JSON、facts 类型不对：verdict 是 `error`（设施故障），不是 `reject`。
5. 写 `tests/system/test_gate.py`（至少 5 个），再跑验收。

```python

# ✔ verdict = 'error'  # Runner 记 GATE_ERROR，计入 failed 重试
```

**用 Python eval 算 accept**

```python
# ✖ eval(expr, {'out': out})
# ✔ snapshot.compiled(f'{station}/outputs.{port}.accept[{i}]').evaluate(env)
```
