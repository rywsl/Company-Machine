## 错误示范与正确示范

**回滚用 reset**

```python
# ✖ git reset --hard <base>
# ✔ epochs.rollback(base, by=actor)  # 只动指针，不碰 refs/heads/*
```

**每次 build 都覆盖解析表**

```python
# ✖ write(resolutions.json)
# ✔ if not path.exists(): write_atomic(path, ...)  # I14 依赖它不变
```

**检出 epoch 用 checkout**

```python
# ✖ git checkout <commit>
# ✔ git archive --format=tar <commit> | tarfile 解到 epochs/<commit>/registry
```

## 规范没写到时

- 引用更新失败不回滚表：表是声明态，引用由调和器恢复。

- 不要修改受保护文件（`plan/protected.lock` 登记的规范、验收测试、夹具、harness）。hook 会拒绝；绕过也会被 `lock --verify` 发现。
- 不要新增依赖，不要调用任何 LLM API，不要 `shell=True`，不要在 `base.py` 以外读时钟或生成随机数。
- 不要实现后续任务的功能；碰到“下一步才需要”的东西，按规范的“不做什么”表拒绝。
