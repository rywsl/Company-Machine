## 交付内容

| 命令 | 作用 |
|---|---|
| `mrl eval`、`mrl template` | 求值表达式、渲染模板 |
| `mrl check FILE.mrl...`、`mrl run FILE.mrl... [--facts] [--rel]` | 检查、运行规则程序 |
| `mrl conformance [PATH...] [--json] [-q]`、`mrl coverage [PATH...] [--json]` | 运行一致性用例、统计覆盖率 |
| `mrl registry check ROOT [--json] [--strict] [--no-info]` | 检查 Registry |
| `mrl registry facts ROOT [--rel]`、`mrl registry resolutions ROOT` | 查看抽取的事实、转换解析表 |
| `mrl resolve ROOT --from --to [--guarantees] [--requires] [--via]` | 单独解析一次转换 |
| `mrl explain CODE`、`mrl --version` | 解释错误码、显示版本 |

退出码：

| 退出码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 失败 |
| 2 | 用法错误 |
| 3 | 静态错误 |
| 4 | 运行期错误 |
| 5 | 内部错误 |
