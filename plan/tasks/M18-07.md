# M18-07 正式前端资源与真实数据 hydration

- 状态：未开始
- 前置：M18-06
- 必读：`spec/system/web-app.md` 第 3–10 节、`plan/design-m18-ui.md` 第 2–8、11 节

## 交付

- 在 `src/mao/webapp/static/` 提供正式 HTML、CSS 和 JavaScript
- 默认加载看板，并通过 bootstrap 与按需 API 获取真实数据
- 保留四入口、离屏侧边栏、可拖动 MAO、两层画布、渐进式详情和金属质感
- Foreman 对话只出现在编排画布，默认隐藏且与侧边栏独立
- API 失败显示 connecting、degraded 或 exception，不静默回退到 mock
- 浏览器 localStorage 只保存布局、缩放、平移、MAO 位置和展开偏好

## 验收

- 静态资源可以由 WebServer 返回并通过 `node --check`
- `tests/system/test_m18_web_frontend.py` 验证入口、无登录、多用户文案和 API hydration
- 前端源码不存在旧的固定 mock 图作为正式数据源
- 正式页面不展示密码值或完整技术配置
