## 交付内容

- 流水线：
  1. YAML 1.2 加载；
  2. 目录布局检查；
  3. JSON Schema 检查；
  4. 事实抽取；
  5. 内核 + 宪法第一遍求值；
  6. 嵌入表达式的类型检查；
  7. 带 `host_diag` 的第二遍求值；
  8. 诊断码表校验、定位、排序。
- 名义子类型（`extends`）；`list` 与 `ref` 协变；`texpr_ok` 守卫，避免连锁诊断。
- 转换解析：`resolve` / `resolveVia` 是纯函数，解析表是确定的（不变量 I14）。
- 属性经过转换后的传递规则：`guarantees ∪ (P ∩ preserves) ∪ always(to)`。
- 动态构造的静态规则：map / switch / until / subline。
- 预算：步骤预算 × 倍数，加上自动插入的转换工位的预算。
- 覆盖率：每个诊断码至少被一个用例期待，内核的每条诊断规则至少触发一次。
