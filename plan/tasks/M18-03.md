# M18-03 Foreman、Harness 与自治资源请求

- 状态：设计冻结，等待 M18-02
- 前置：M18-02
- 必读：`spec/system/web-app.md` 第 6、7、10 节、`plan/design-m18-ui.md` 第 5–7 节

## 交付

- Foreman 对话固定在编排画布内，默认隐藏
- Foreman 可以创建厂区、装配员工、检查能力、应用、运行、验证、修复和恢复
- Foreman 与 Operator 都可以选择本地 Harness CLI
- demo 支持 Claude Code、Codex、DeepSeek Harness、Kimi CLI、Zcode、Pi、本地发现和自定义 Harness 的表达
- 正式适配器使用能力声明，不把示例清单做成封闭枚举
- Operator 主动提出资源请求，Foreman 处理请求并继续运行
- 普通业务不显示批准运行、应用候选方案或人工确认

## 验收

- Foreman 开关与侧边栏开关互不影响
- Foreman 自动应用 mock 结构，不出现审批按钮
- Foreman 和 Operator 节点详情都能选择 Harness
- 未识别或不可用 Harness 进入可恢复的适配异常
- 资源请求可以从节点详情、Foreman 和日志进入
