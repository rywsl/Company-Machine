# Dokumentation

<p align="center"><img src="../assets/architecture.svg" alt="Architektur" width="100%"></p>

Diese Anleitungen erklären, wie Sie Machine Agent Org nutzen und daran mitarbeiten. Normative Quellen sind die Spezifikationen: [`spec/system/`](../../spec/system/README.md) für die Steuerungsebene und [`spec/mrl/`](../../spec/mrl/) für die Sprache MRL. Die vollständige Begründung des Entwurfs steht in [`docs/architecture.md`](../architecture.md), verfasst auf Chinesisch. Widersprechen sich eine Anleitung und eine Spezifikation, gilt die Spezifikation.

| Anleitung | Lesen Sie sie, wenn Sie … |
|---|---|
| [Erste Schritte](getting-started.md) | in etwa zehn Minuten installieren, prüfen und Ihre erste Linie ausführen möchten |
| [Konzepte](concepts.md) | Beans, Typen, Maschinen, Stationen, Linien, Verträge, Epochs und die Prüfschichten verstehen möchten |
| [Laufzeit](runtime.md) | sehen möchten, was zur Laufzeit passiert: Prozesse, Job-Lebenszyklus, Sandboxes, Speicherung, Beobachtbarkeit, bekannte Lücken |
| [CLI-Referenz](cli.md) | einen `factory`- oder `mrl`-Befehl nachschlagen möchten |
| [Entwicklung](development.md) | mitarbeiten möchten: Harness-Workflow, Meilensteine, geschützte Dateien, Tests |

## Empfohlene Lesereihenfolge

1. **Neue Nutzer:** Erste Schritte → Konzepte → CLI-Referenz.
2. **Betreiber, die die Fabrik unbeaufsichtigt laufen lassen:** Laufzeit (Abschnitte zu `serve`, Beobachtbarkeit und Backup) → CLI-Referenz.
3. **Mitwirkende:** Entwicklung → Konzepte → die Spezifikation der Komponente, die Sie ändern.
