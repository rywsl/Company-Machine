# Документация

<p align="center"><img src="../assets/architecture.svg" alt="Архитектура" width="100%"></p>

Эти руководства объясняют, как пользоваться Machine Agent Org и как участвовать в его разработке. Нормативные источники — спецификации: [`spec/system/`](../../spec/system/README.md) для плоскости управления и [`spec/mrl/`](../../spec/mrl/) для языка MRL. Полное обоснование архитектуры изложено в [`docs/architecture.md`](../architecture.md) на китайском языке. Если руководство расходится со спецификацией, права спецификация.

| Руководство | Читайте, если хотите… |
|---|---|
| [Начало работы](getting-started.md) | примерно за десять минут установить, проверить и запустить свою первую линию |
| [Основные понятия](concepts.md) | разобраться в Bean, типах, машинах, станциях, линиях, контрактах, эпохах и уровнях проверки |
| [Среда выполнения](runtime.md) | увидеть, что происходит во время работы: процессы, жизненный цикл заданий, песочницы, хранение, наблюдаемость, известные недоработки |
| [Справочник CLI](cli.md) | найти команду `factory` или `mrl` |
| [Разработка](development.md) | участвовать в разработке: рабочий цикл harness, вехи, защищённые файлы, тесты |

## Рекомендуемый порядок чтения

1. **Новые пользователи:** Начало работы → Основные понятия → Справочник CLI.
2. **Те, кто эксплуатирует фабрику без присмотра:** Среда выполнения (разделы о `serve`, наблюдаемости и резервном копировании) → Справочник CLI.
3. **Участники разработки:** Разработка → Основные понятия → спецификация компонента, который вы меняете.
